# DealHunter デモ操作ガイド

## 起動とログイン

作業フォルダで `npm.cmd run demo` を実行し、http://127.0.0.1:3100/login を開きます。

営業・エンジニア・リーダーそれぞれのデモ入力ボタンを押し、その後「ログイン」を押します。エンジニア9名とリーダー2名は選択欄で切り替えられます。リーダーのパスワードは共通で `demo-leader` です。別アカウントで試す際はヘッダーからログアウトします。

## 新規アカウントを登録する

1. ログイン画面の「新規アカウント登録」から登録画面へ進みます。
2. 氏名、会社のメールアドレス、10〜128文字のパスワードと確認用パスワードを入力します。メールは `@legarea.jp` だけを受け付けます。`@sub.legarea.jp` や `@evillegarea.jp`、`@legarea.jp.example` は登録できません。
3. 現在の役割を「エンジニア」「リーダー」「営業」から選択し、「アカウントを登録」を押します。登録後は選んだ役割のホームへ移動します。
4. 次回からは登録したメールアドレスとパスワードでログインします。エンジニアの所属リーダーは、管理者画面から設定できます。

管理者は一般の新規登録では選択できません。パスワードは個別のソルト付きPBKDF2-HMAC-SHA256（600,000回）でハッシュ化して保存します。メールドメインの形式を確認する機能であり、メールの所有確認やパスワード再発行は未実装です。HTTPSでの外部公開にも対応していません。

## 管理者が役割と所属を変更する

初回起動で作成される管理者のメールアドレスは `admin@legarea.jp` です。初期パスワードは、その環境の `.local/initial-admin-password.txt` を開いて確認します。通常のログイン画面で入力すると、アカウント管理が開きます。既存のデモアカウントも引き続き利用できます。

1. 利用者一覧で氏名・メールアドレス・所属リーダーを検索し、編集する人を選びます。役割による絞り込みもできます。
2. 「変更後の役割」でエンジニア／リーダー／営業／管理者を選択します。エンジニアの場合は「所属リーダー」も選べます。「所属なし」にすることもできます。
3. 「変更内容を確認」で変更前後の役割と所属を確認します。「編集に戻る」で選び直し、「この内容で保存」で確定します。
4. 変更した利用者の次のアクセスから、新しい役割のホームと権限が適用されます。ログイン中でもDB上の役割を照会し、過去の面談・所感・案件は削除しません。

部下が所属中、または面談者の選定待ち案件があるリーダーは、そのまま別の役割に変更できません。部下の所属を他のリーダーまたは「所属なし」へ変更し、選定待ちはリーダーが選定を完了してから役割を変更してください。最後の管理者の役割も変更できません。別の管理者を先に設定する必要があります。

自分を管理者以外の役割に変更すると、保存後に新しい役割のホームへ移動します。アカウントと所属はDBに保存され、再起動で初期設定に戻りません。

## 営業とエンジニアをまたぐ通し操作

営業は全営業の案件・面談・所感・初回入場を閲覧できます。以下の日時確定、結果登録、添付の差し替えといった営業の更新操作は、案件を作成した担当営業で行います。他担当の案件は閲覧しても「対応待ち」の確認状態は変わりません。

1. 営業（青木 美咲）でログインし、「面談依頼を作成」を開きます。案件名・上位会社・概要を入力し、エンド企業は分かる場合に入力します。担当リーダーに「佐藤 健一」を選びます。面談者の選定方法は「営業が面談者を指定する」にして、「高橋 蓮」「山本 葵」をチェックします。「候補日時を提示する」で開始日時を複数入力し、保存前の確認で会社名・リーダー・面談者全員を確認して保存します。終了時刻は入力しません。面談者は1名でも登録できます。
2. 通知の送信内容を確認します。Larkへは送信されず、アプリ内の履歴に残ります。
3. ログアウトしてエンジニア（高橋 蓮）で入り、「面談依頼」から今作った依頼を開きます。参加できる候補を複数選んで営業へ直接回答します。山本 葵で入ると山本宛ての依頼だけが表示され、回答は高橋と独立しています。
4. 営業で入り直し、「対応待ち N件／未確認 X件」を確認します。回答された依頼を選ぶと「確認済み」になり、未確認数だけが減ります。回答済みの候補を選んで日時を確定します。複数人の面談では候補の比較表を開き、全員が参加できる時刻を選んで一括確定できます。URLが未着なら、日時を先に確定し、後で「対応待ち」から追記します。
5. エンジニアで入り直し、「予定」で事前打合せと本面談をそれぞれ開きます。会議ID、接続手順、緊急連絡先などを読み、「最新の案内を確認しました」を押します。営業と担当リーダーに確認状況が表示されます。
6. 「所感・質問」から該当面談を選び、業務内容・作業工程・リモート頻度・感想を入力します。質問は1問ずつ追加して提出します。
7. 営業で入り直し、「対応待ち」に新しい未確認の「面談結果・初回入場を登録」が届くことを確認します。提出内容と「質問集」も確認します。質問は案件に紐づき、案件詳細の過去質問にも表示されます。
8. その対応待ちから結果と初回入場の登録へ進みます。合格の場合は初回入場日時・集合場所・当日の案内を入力して保存します。不合格の場合は入場予定を作成しません。登録が完了すると、該当する対応待ちは一覧から外れます。
9. エンジニアで入り直し、「予定」で初回入場の集合時刻・集合場所・案内を確認します。
10. 面談詳細に表示される合否を読んで「確認」を押すと、その面談がエンジニアの予定一覧から外れます。初回入場の予定は別に残ります。
11. 初回入場が完了したら、その入場詳細の「確認」を押します。予定一覧から「入場中」へ移動し、入場中の案件概要・集合案内・元の面談や所感を引き続き参照できます。複数の案件がある場合も、それぞれの入場を確認して一覧に追加できます。

「確認済み」は内容を閲覧した状態で、対応完了とは別です。閲覧しても対応待ち総数は減りません。確認状態は再読み込み後も残りますが、日時確定前にエンジニアが候補を再回答すると、同じ依頼でも再び未確認になります。所感提出後の結果登録は別の対応待ちとして届くため、以前の確認済み状態は引き継ぎません。

初回入場が決まった後も、入場詳細の「案件概要」「元の面談」から面談時の内容・日時・URLを確認できます。「元の面談を見る」で面談詳細へ、「提出した所感を見る」（営業では「所感・聞かれた質問を見る」）で提出済みの記録へ進めます。営業・エンジニアの両方で利用できます。

同じタブで再読み込みしても入力済みの業務データは残ります。別タブを使う場合は、タブに戻るか再読み込みすると最新データを取得します。

エンジニアの「確認」はボタンを押した時に保存されます。結果を確認できるのは結果登録後です。参加案内は日時が決まった時点から確認でき、共有内容が変わると本人に再確認が表示されます。予定を開くだけでは移動せず、保存に失敗した時も元の一覧に残ります。確認状態は再ログイン・再起動後も保持され、営業側の予定や記録は削除されません。

## 面談者を未定にしてリーダーへ選定を依頼する

新規依頼で「依頼内容・Lark通知を確認」を押すと、他の営業の登録も含めた類似案件が表示される場合があります。「案件を確認」で概要を読み、担当営業と照合できます。「入力に戻る」で下書きを編集でき、「このまま確認へ進む」で保存前の確認へ進みます。

1. 営業の「面談依頼を作成」で案件名・上位会社・概要・担当リーダーを入力し、エンド企業は任意で入力します。面談者の選定方法を「リーダーに面談者の選定を依頼する」に切り替えます。面談者はチェックせず、日程条件・任意の参画者や共通スキルシートを入力します。
2. 保存前の確認で「面談者はリーダーが選定」と依頼先リーダーを確認し、保存します。営業の「作成した面談依頼」に選定待ちの案件が表示され、「選定状況を見る」から進捗を確認できます。この時点ではエンジニア本人の依頼は作成されません。
3. 担当リーダーで入り直し、担当案件の「面談者の選定待ち」を開きます。案件概要と日程条件を確認して、自分のチームの部下を1名以上選びます。「選んだ面談者を確認」の後、「この面談者で確定する」を押します。
4. 選定が完了すると、選ばれた各エンジニアに面談依頼が作成され、営業には選定完了の通知プレビューが残ります。エンジニア本人で入り直すと、自分宛ての依頼から日程を回答できます。
5. 以降は上記の通し操作と同様に、本人が候補へ回答し、営業が面談日時・URLを確定します。リーダーが日程回答や日時確定を代行することはできません。

承認済みのデモ所属は次のとおりです。佐藤の案件では佐藤の5名、鈴木の案件では鈴木の4名から選定します。

| リーダー | 選定できる部下 |
| --- | --- |
| 佐藤 健一 | 高橋 蓮、山本 葵、森 彩乃、伊藤 航、小林 悠 |
| 鈴木 遥 | 佐々木 凛、田中 陸、木村 楓、井上 葵 |

担当外のリーダーや他チームの部下は選定できません。確定後の選び直しには対応していません。営業が直接面談者を指定する従来の方法も利用できます。

## 日時を決めずに空き日時を確認する

どの依頼方法でも、新規作成時の「上位会社（必須）」は1〜200文字、「エンド企業（任意）」は200文字以内です。空白だけの上位会社は保存できません。保存前の確認・保存後の依頼詳細・面談や初回入場の詳細で会社情報を参照できます。既存案件で会社情報がない場合は未登録・未入力の表示になり、日程回答や日時確定は継続できます。

営業の「面談依頼を作成」で、日程の調整方法を「面談者に空き日時を確認する」に切り替えます。

- 日付・時刻とも未定の場合は、日付の指定を空のまま保存します。
- 日付だけ決まっている場合は、カレンダーで複数の日付を選択し、開始時刻を入力せずに保存します。月を移動して別の月の日付も選択できます。同じ日付をもう一度押すと解除でき、「すべて解除」で日時未指定に戻せます。

エンジニアは自分宛ての依頼を開き、「都合のよい日時を回答」で日付と開始時刻を入力します。「候補日時を追加」で複数回答でき、日付指定がある場合はその日付から選択します。日時は日本時間です。

全候補が難しければ理由とともに回答するか、別の日・時間帯を提案できます。営業は「対応待ち」から再依頼、または回答に合う開始日時を選んで確定します。URLは後から登録できます。確定前であればエンジニアは回答を変更でき、再回答は営業側で再び未確認になります。確定後は候補を変更できません。

確定した日時が変わったときは、営業が面談詳細から日時変更・延期・中止を選び、理由を入力します。以前の日時は面談履歴で確認できます。

所感提出後の先方評価と次回準備は、該当する面談回を開いて入力します。準備事項は本人に表示され、先方評価は本人への共有を選べます。結果確認後の公開更新は、エンジニアの「予定」にある「面談後に届いた案内」から読めます。

開始時刻だけの面談には終了時刻を自動補完しません。従来登録した終了時刻付きのデータは保持されます。

## 会社とエンジニアの面談担当NGを検索する

1. 営業メニューの「OK・NG検索」を開きます。「会社から探す」で社名を入力すると、その会社に対する登録エンジニア全員のOK／NGが表示されます。上位会社・元請け・エンド企業の区分でも絞れます。
2. 「エンジニアから探す」で氏名を入力すると、その人に対する会社ごとの判定が表示されます。上位会社・元請け・エンド企業のいずれかが過去の面談先と一致すると「面談履歴あり」のNGが付きます。
3. 履歴にない会社を追加するには「面談担当NGを手動登録・解除」を開き、対象のエンジニアを選んで会社名を入力し、「面談担当NGに登録」を押します。全営業で共有され、上位会社・元請け・エンド企業のすべてに適用されます。自分の登録を解除した後も、面談履歴の一致や別の営業の登録が残る場合はNGです。

## スキルシートの添付とダウンロード

営業の「面談依頼を作成」で、面談者の下に「参画者」「参画者(ひらがな)」を入力できます。面談者とは異なる方を自由に登録でき、面談者の選択を変えても参画者名は上書きされません。両方とも任意入力で、ふりがなを入力する場合はひらがなを使用します。

スキルシートの添付欄は案件共通の1つです。PDF・Excel（xls/xlsx）・Word（doc/docx）、5MB以下を選択でき、同じ案件で選択したすべての面談者が同じファイルをダウンロードします。保存前の確認で、面談者・参画者・共通ファイル名を確認してください。

リーダーへの選定依頼でも、作成時に共通ファイルを保存できます。営業の選定状況画面ではファイル名を確認でき、選定後は各本人の依頼から同じファイルを取得できます。リーダーは添付ファイルを取得できません。

面談者別の依頼が作成された後は、担当営業の「対応待ち」内の「作成した面談依頼」から本人ごとの詳細を開き、共通ファイルを追加・差し替えできます。差し替えは同じ案件の全面談者へ反映されます。他の営業もファイルをダウンロードできます。受講者は自分の依頼詳細、関連する面談・入場詳細から「スキルシートをダウンロード」を押せます。案件外の受講者やリーダーは取得できません。

旧形式の個人別ファイルは自動共有せず保持します。共通ファイルが未設定の間は、本人の旧ファイルだけを表示します。共通ファイルを登録すると、全員がその共通ファイルを参照します。

## リーダーの状況確認

佐藤 健一でログインすると、自分がリーダーに選択された案件を一覧で確認できます。1案件の中に面談者全員の進捗が並び、案件を開くと概要・候補回答・確定日時／URL・所感／質問・合否・初回入場・入場中の記録を閲覧できます。面談者本人が確認して予定から外れた後も、リーダーには履歴が残ります。

検索は案件名・面談者名、絞り込みは「面談者の選定待ち」や各面談者の状態で行います。スマートフォンは案件をタップして詳細を読み、「一覧へ戻る」で戻れます。鈴木 遥には佐藤の案件は表示されません。リーダーが更新できるのは担当の未選定依頼に対する面談者選定だけです。選定後の回答・所感は本人、日時確定・合否・初回入場登録は営業が直接操作し、リーダーは引き続き状況を閲覧します。既存案件にはリーダーを自動割当せず、新しい依頼作成時に明示して選択します。

## 空の状態から確認する

新しいDBはデモアカウント・初期管理者・チーム所属だけの状態から始まります。営業で面談依頼を作成するまでは一覧が空です。すでに登録した利用者や案件がある環境では、そのデータは保持されます。

営業が直接指定したエンジニア、またはリーダーが選定を確定したエンジニアで入り直すと、その人宛ての依頼を確認できます。リーダーの選定待ちの間は本人宛ての依頼はまだありません。以降は上記の通し操作で進められます。サンプル案件を起動時に追加する処理は外しているため、再起動後も登録した案件だけが表示されます。

デモを一度に通して確認できるよう、面談日が未来でも自分の面談に所感を登録できます。すべて架空データを使用してください。Lark通知と外部カレンダーは送信内容のプレビューまでです。
