## 再確認コマンド

プロジェクトのルートから実行します。統合テストは専用案件を作るため、ブラウザでの登録・更新と同時には実行しないでください。

```powershell
npm.cmd run build
npm.cmd run verify:auth
powershell -NoProfile -ExecutionPolicy Bypass -File backend/verify.ps1
node backend/verify-attachment.mjs
```

多段の保存保持テスト（leader-multi／task-ack）は、スクリプトが表示する再起動・persisted・continue・cleanupの手順に従います。
